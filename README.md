# 퀼브릿지 회사 자료

퀼브릿지 홈페이지와 회사 소개 자료의 편집 가능한 원본을 관리하는 저장소입니다.

## 자료 관리

- `website/`: 홈페이지 소스와 실행 안내
- `documents/company-profile/`: 회사소개서 원본 및 배포본
- `documents/brochure/`: 브로슈어 PPTX 원본 및 배포본
- `assets/`: 로고, 사진, 공용 이미지

위 경로는 자료를 추가할 때 생성합니다. 현재 홈페이지 소스와 회사소개서·브로슈어 원본은 업로드되지 않았습니다.

## 편집 방법

이 저장소를 복제한 뒤 원본 파일을 편집하고, 변경 사항을 커밋하여 푸시합니다. 다른 기기에서는 최신 변경 사항을 가져온 뒤 작업하세요.

```sh
git clone https://github.com/newclow-bot/company.git
cd company
git pull --ff-only
```

PPT는 편집 가능한 `.pptx` 원본을 보관하고, 배포용 PDF가 있으면 원본과 함께 관리합니다. 홈페이지 설치 및 실행 방법은 소스가 추가되면 기록합니다.

비밀번호, API 키, 고객 개인정보 등 민감한 자료는 커밋하지 마세요.
